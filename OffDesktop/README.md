# OffDesktop

Desligue seu PC pelo celular (mesma rede Wi-Fi).

## PC
1. Instale o Node.js (nodejs.org).
2. Na pasta do projeto: `npm install` e depois `npm start`.
3. Na primeira execução o Windows pede permissão de firewall: permita em redes privadas.
4. A janela de pareamento mostra o endereço e o código de 6 dígitos.
5. Para gerar o instalador: `npm run dist`.

## Celular
Abra o endereço no navegador, digite o código e use "Adicionar à tela inicial".
